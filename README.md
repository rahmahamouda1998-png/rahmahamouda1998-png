## How I test
- **Start from the acceptance criteria**, then look for the edges: midnight and time zones, month boundaries, empty states, extra spaces, Arabic text.
- **Make AI features testable** with source documents that contain known values, so an answer is a clear pass or fail.
- **One bug, one clear report**: preconditions, steps, expected vs. actual, environment and evidence.
